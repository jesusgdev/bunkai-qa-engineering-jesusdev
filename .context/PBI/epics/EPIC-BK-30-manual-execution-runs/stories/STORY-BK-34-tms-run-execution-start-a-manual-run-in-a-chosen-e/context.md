### Edge Cases Raised

- Same token within 24 hours returns the existing Run and creates no duplicate checklist.
- Different token creates a separate Run.
- Test with no executable steps blocks Run creation and creates no partial records.
- Invalid Project Environment blocks Run creation.
- Agent/CI executor mode must be stored correctly.
- Newly started Run must appear in Test run history.

### Open Clarifications

- PO: Should executable source be manual steps, ATC links, or both? Current testing should focus on executable steps.
- Design: Confirm exact success state after Run creation.
